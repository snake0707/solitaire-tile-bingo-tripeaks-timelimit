## 核心变化模式

v3 把很多 v2 的类别名改成了更具体/更贴切的名字，但 word 内容基本不变：
- `Whiskers` → `Animals` / `Big cats` / `Primates`（按动物类型拆分）
- `Bird` → `Birds` / `Parrots` / `Egg`（按鸟的特征细分）
- `Chair` → `Seats`，`Shapes` → `Polygons`（更通用的命名）
- 少量 word 内容调整（如修正拼写 "let"→"Piglet"，替换不合适的 word）
